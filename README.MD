
# GLITCH RUSH 🐱⚡

A fast-paced browser arcade game created for the
Hack Club Arcade card.

## The Game

Control a cyber-cat, collect 12 golden bytes in
45 seconds, and escape the glitch storm!

## Controls

- WASD / Arrow keys: Move
- Mouse / Touch: Hold and drag to move
- Space / Shift: Dash
- R / Enter: Restart after a round
- Sound button: Toggle sound

## Features

- Chasing enemies
- Three-heart health system
- Score and countdown timer
- Win and lose conditions
- Dash cooldown
- Particle effects and sound effects
- Saved best score
- Touch controls

## Technology

HTML5 Canvas, CSS, and vanilla JavaScript.

All graphics are drawn in code.
Sound effects are generated with Web Audio.
No third-party assets, frameworks, or API keys.

## How to Play

Open index.html in any modern desktop or
mobile browser.

No installation or account required.
